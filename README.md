# Лабораторная работа: Восстановление BMP-изображения сортировкой Шелла (шаги Седжвика)

**Автор:** Сайдов Данила  
**Язык реализации:** Python 3  

---

## Описание задачи

Программа предназначена для восстановления исходного растрового изображения формата **BMP** (24 или 32 бита) из файла с перемешанными пикселями на основе текстового файла с ключами перестановки.

### Ключевые особенности реализации
* **Ручной парсинг BMP:** Чтение и запись заголовков (`BITMAPFILEHEADER`, `BITMAPINFOHEADER`) и пиксельных строк выполнены вручную без использования сторонних графических библиотек, с полным учетом выравнивания строк (**padding**).
* **Сортировка Шелла с шагами Седжвика:** Итеративная реализация с генерацией последовательности шагов $1, 5, 19, 41, 109, 211 \dots$ обеспечивает асимптотическую сложность в среднем $O(n^{1.167})$.
* **Абсолютная устойчивость:** Реализована защита от нарушения порядка дубликатов за счет расширения ключа порядковым индексом.
* **Автоматическая визуализация (Повышенный уровень):** Поддержка генерации промежуточных кадров и автоматической сборки MP4-видеоролика процесса сортировки с последующей очисткой диска.

## Состав репозитория

* `restore.py` — основной исполняемый модуль программы (чтение BMP, алгоритм сортировки, замер времени, генерация видео).
* `config.json` — конфигурационный манифест для автоматической тестирующей системы.
* `README.md` — документация и инструкция по запуску.
* `.gitignore` — правила исключения временных файлов.

## Установка и запуск

Для работы базового функционала (восстановление и бенчмарк) сторонние библиотеки не требуются. Для автоматического рендеринга видеороликов необходим пакет `opencv-python`:

```bash
py -m pip install opencv-python --user
```

### Примеры команд запуска

**1. Базовое восстановление изображения:**
```bash
py restore.py --bmp shuffled.bmp --keys keys.txt --out restored.bmp
```

**2. Режим замера чистого времени сортировки (вывод медианы по 7 проходам):**
```bash
py restore.py --bmp shuffled.bmp --keys keys.txt --out restored.bmp --bench 7
```

**3. Визуализация процесса сортировки (сборка видео `sorting_process.mp4`):**
```bash
py restore.py --bmp shuffled.bmp --keys keys.txt --out restored.bmp --animate 10000
```
